# QA Automation Projects

[![Playwright QA checks](https://github.com/SnnY-cyber/qa-automation-projects/actions/workflows/tests.yml/badge.svg?branch=main)](https://github.com/SnnY-cyber/qa-automation-projects/actions/workflows/tests.yml) [![Selenium UI tests](https://github.com/SnnY-cyber/qa-automation-projects/actions/workflows/selenium-python.yml/badge.svg?branch=main)](https://github.com/SnnY-cyber/qa-automation-projects/actions/workflows/selenium-python.yml) [![Postman API checks](https://github.com/SnnY-cyber/qa-automation-projects/actions/workflows/postman-newman.yml/badge.svg?branch=main)](https://github.com/SnnY-cyber/qa-automation-projects/actions/workflows/postman-newman.yml)

A portfolio bundle of test automation samples based on my QA work across web, API, and mobile products.

- [Playwright web + API automation](web-api-automation/README.md): E2E checkout, API contract and visual regression examples.
- [Selenium + Python UI regression](python-selenium/README.md): checkout flow, invalid login, explicit waits, failure screenshots and CI.
- [Postman + Newman API checks](postman/README.md): collection-driven contract, create and negative-path tests.
- [Appium mobile starter](mobile-appium-starter/README.md): WebdriverIO Android smoke test with a Page Object.
- [Jenkins pipeline](Jenkinsfile): Selenium and Newman stages with test artifacts.
- [Manual QA samples](web-api-automation/manual-qa-samples.md): checkout scenario and sample bug report.

Projects target public demo apps and contain no secrets or production data. Update each README with your own notes as you extend the examples.
